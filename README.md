# 📼 ДОЗОР-4: Ночная Смена (DOZOR-4: Night Shift)

> Атмосферный психологический 3D VHS-хоррор от первого лица на WebGL / Three.js.
> Выживите в ночную смену смотрителя с **00:00 до 06:00**, устраняя паранормальные аномалии в заброшенной советской комнате наблюдения.

🌐 **Играть онлайн (GitHub Pages):**  
👉 **[https://waykegoat.github.io/horror/](https://waykegoat.github.io/horror/)**

---

## 🎮 Игровой процесс

Игрок находится в изолированном помещении поста наблюдения. Каждая минута приближает рассвет, но активность паранормальной сущности нарастает с каждым часом. Начиная с 01:00, аномалии могут возникать **одновременно**, требуя молниеносной реакции.

Ваша задача — следить за датчиками на 3D-мониторе стола и ручном тактическом планшете, вовремя устраняя 4 типа угроз:

| Аномалия | Симптом | Действие игрока | Лимит времени |
| :--- | :--- | :--- | :--- |
| 📺 **Телевизор «Рубин»** | Включается белый шум, жуткое лицо в кинескопе | Подойти и выключить клавишей `[E]` | 10 сек |
| 🪟 **Окно в сад** | Силуэт за стеклом, скрежет когтей | Задёрнуть плотные шторы клавишей `[E]` | 9 сек |
| 🚪 **Бронированная дверь** | Глухие удары, звон петель и засова | Закрыть стальной засов клавишей `[E]` | 8.5 сек |
| ⚡ **Электрощиток** | Искры, просадка сети, **полный блэкаут** | Перезагрузить автомат клавишей `[E]` | 11.5 сек |

> 🚨 **Механика Блэкаута:** При сбое щитка через 4 секунды люстра полностью гаснет. Комната погружается во тьму с тусклым аварийным красным маяком. Скорость роста шкалы угрозы возрастает в **2.5 раза**!

Если уровень угрозы достигает 100% или любая аномалия не устранена вовремя — следует внезапная скример-атака сущности и поражение. В 06:00 комната заливается солнечными лучами, наступает победа.

## 🕹 Управление

- **W, A, S, D** — Перемещение по комнате
- **Мышь** — Осмотр (захват курсора по клику)
- **E** — Взаимодействие с объектами (телевизор, шторы, дверь, щиток)
- **TAB / Q** — Приблизить / осмотреть ручной **3D-планшет «ДОЗОР-4»**
- **Esc** — Пауза / вызов терминала
- **Тач-управление** — Поддержка мобильных устройств (виртуальный стик, зона осмотра и кнопки)

## 💻 Технический стек и реализм

- **Графика и рендер**: Three.js (r128), `ACESFilmicToneMapping`, мягкие тени `PCFSoftShadowMap`.
- **Процедурные PBR-материалы**: Тисненые советские обои со следами штукатурки и трещинами, дубовый наборный паркет «елочка», шерстяной ковер с восточным медальоном, чугунный радиатор, дисковый телефон ТА-68.
- **Атмосфера**: Система из 400 парящих пылинок (`THREE.Points`) в лучах света, подвесная люстра с нитью накаливания.
- **Диегетический 3D-интерфейс**:
  - Физический монитор на столе с живым радаром сектора.
  - Ручной 3D-планшет с физической инерцией (spring sway), живым ЭКГ-пульсометром оператора, часами смены и светодиодами угрозы.
  - 3D-пространственные голографические маркеры в мире над активными зонами.
- **Пост-обработка**: Кастомный шейдер VHS (эффект выпуклого кинескопа, сканлайны, аналоговый шум, хроматическая аберрация).
- **Аудио-система**: Web Audio API (полностью процедурный синтез: белый шум, скрежет, удары в дверь, звон разбитого стекла, звук отключения турбины при блэкауте, биение сердца `lub-dub`).
- **Зависимости**: **0 внешних npm-зависимостей** (всё работает автономно в браузере).

## 📁 Структура проекта

```
horror/
├── index.html                  # 3D CRT-терминал, меню и холст игры
├── server.js                   # Легковесный Node.js сервер
├── package.json                # Конфигурация проекта
├── .nojekyll                   # Деплой на GitHub Pages
├── src/
│   ├── main.js                 # Точка входа приложения
│   ├── style.css               # Стилизация 3D-монитора, HUD и CRT-эффектов
│   ├── core/
│   │   └── Game.js             # Главный игровой цикл, таймер смены, ИИ аномалий, скримеры
│   ├── world/
│   │   └── RoomScene.js        # 3D комната, PBR-мебель, свет, пылинки, блэкаут
│   ├── entities/
│   │   ├── RoomPlayer.js       # Контроллер игрока (WASD, mouse look, bobbing, shake)
│   │   └── Tablet3D.js         # Диегетический 3D-планшет с живой CanvasTexture
│   ├── audio/
│   │   └── HorrorAudio.js      # Процедурный синтезатор звуков и эмбиента
│   ├── textures/
│   │   └── TextureGenerator.js # PBR-текстуры (обои, паркет, ковер, телефон, помехи)
│   ├── shaders/
│   │   └── VHSShader.js        # GLSL шейдер VHS-эффектов
│   └── postprocessing/
│       └── PostProcessor.js    # Компоновщик эффектов Three.js
└── vendor/
    ├── three.module.js         # Three.js core
    └── addons/                 # EffectComposer, Pass, ShaderPass
```
