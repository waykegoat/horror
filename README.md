# 📼 ДОЗОР-4: Ночная Смена (DOZOR-4: Night Shift)

> Атмосферный психологический 3D VHS-хоррор от первого лица на WebGL / Three.js.
> Выживите в ночную смену смотрителя с **00:00 до 06:00**, устраняя паранормальные аномалии в заброшенной советской комнате наблюдения.

## 🎮 Игровой процесс

Игрок находится в изолированном помещении поста наблюдения. Каждая минута приближает рассвет, но активность паранормальной сущности нарастает с каждым часом.

Ваша задача — следить за датчиками на мониторе и вовремя устранять 4 типа угроз:

| Аномалия | Симптом | Действие игрока |
| :--- | :--- | :--- |
| 📺 **Телевизор «Рубин»** | Включается белый шум, лицо в помехах | Подойти и выключить клавишей `[E]` |
| 🪟 **Окно в сад** | Силуэт снаружи, скрежет когтей по стеклу | Задёрнуть плотные шторы клавишей `[E]` |
| 🚪 **Бронированная дверь** | Глухие удары, дребезжание ручки | Закрыть стальной засов клавишей `[E]` |
| ⚡ **Электрощиток** | Искры, мерцание люстры, падение напряжения | Перезагрузить автомат клавишей `[E]` |

Если уровень угрозы достигает 100% — наступает критический прорыв сущности. В 06:00 комната заливается рассветными лучами, наступает победа.

## 🕹 Управление

- **W, A, S, D** — Перемещение по комнате
- **Мышь** — Осмотр (захват курсора по клику)
- **E** — Взаимодействие с объектами (телевизор, шторы, дверь, щиток)
- **Esc** — Пауза / вызов терминала
- **Тач-управление** — Поддержка мобильных устройств (виртуальный джойстик и кнопки взаимодействия)

---

## 💻 Технический стек

- **Движок**: Three.js (r128)
- **Пост-обработка**: Кастомный шейдер VHS (эффект выпуклого кинескопа, сканлайны, аналоговый шум, хроматическая аберрация)
- **Аудио-система**: Web Audio API (полностью процедурный синтез: белый шум, скрежет, удары в дверь, биение сердца, искры)
- **Интерфейс**: Аппаратная консоль «ДОЗОР-4» с интерактивным 3D-наклоном (CSS 3D perspective tilt), фосфорным свечением и светодиодными индикаторами
- **Зависимости**: **0 внешних npm-зависимостей** (всё работает на нативном HTTP-сервере Node.js и нативных ES-модулях)

## 🚀 Быстрый запуск

### 1. Запуск через Node.js:
```bash
# Запуск локального сервера (не требует npm install)
npm start
```
Откройте в браузере: `http://localhost:3000`

### 2. Запуск через любой другой статический сервер:
```bash
# Python 3
python -m http.server 3000

# Либо через расширение Live Server в VS Code
```

## 📁 Структура проекта

```
horror/
├── index.html                  # 3D CRT-терминал, меню и холст игры
├── server.js                   # Легковесный Node.js сервер
├── package.json                # Конфигурация проекта
├── src/
│   ├── main.js                 # Точка входа приложения
│   ├── style.css               # Стилизация 3D-монитора, HUD и CRT-эффектов
│   ├── core/
│   │   └── Game.js             # Главный игровой цикл, таймер смены, ИИ аномалий
│   ├── world/
│   │   └── RoomScene.js        # 3D комната, мебель, свет, интерактивные объекты
│   ├── entities/
│   │   └── RoomPlayer.js       # Контроллер игрока (WASD, mouse look, bobbing)
│   ├── audio/
│   │   └── HorrorAudio.js      # Процедурный синтезатор звуков
│   ├── textures/
│   │   └── TextureGenerator.js # Процедурные текстуры (обои, паркет, помехи)
│   ├── shaders/
│   │   └── VHSShader.js        # GLSL шейдер VHS-эффектов
│   └── postprocessing/
│       └── PostProcessor.js    # Компоновщик эффектов Three.js
└── vendor/
    ├── three.module.js         # Three.js core
    └── addons/                 # EffectComposer, Pass, ShaderPass
```
